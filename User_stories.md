## User Stories

| ID | Роль | User Story | Приоритет |
|:---:|------|------------|:---------:|
| US-01 | Новый пользователь | Как новый пользователь, я хочу зарегистрироваться в GuardLink, чтобы получить личный кабинет и сохранять результаты своей активности. | Must |
| US-02 | Пользователь | Как пользователь, я хочу войти в аккаунт, чтобы получить доступ к истории проверок, уровню и достижениям. | Must |
| US-03 | Пользователь | Как пользователь, я хочу проверить подозрительную ссылку, чтобы понять, безопасно ли по ней переходить. | Must |
| US-04 | Пользователь | Как пользователь, я хочу видеть Risk Score и уровень риска, чтобы быстро оценить опасность ссылки. | Must |
| US-05 | Пользователь | Как пользователь, я хочу видеть причины оценки, чтобы понимать, почему ссылка считается подозрительной. | Must |
| US-06 | Пользователь | Как пользователь, я хочу, чтобы GuardLink проверял ссылку по собственной базе угроз и через VirusTotal, чтобы получить более точный результат. | Must |
| US-07 | Пользователь | Как пользователь, я хочу видеть историю своих проверок, чтобы возвращаться к ранее проверенным ссылкам. | Must |
| US-08 | Пользователь | Как пользователь, я хочу получать опыт за обнаружение новой подтвержденной фишинговой ссылки, чтобы мой вклад в безопасность сервиса учитывался. | Should |
| US-09 | Пользователь | Как пользователь, я хочу повышать уровень при накоплении опыта, чтобы видеть свой прогресс. | Should |
| US-10 | Пользователь | Как пользователь, я хочу получать достижения за определенные действия, чтобы иметь дополнительную мотивацию пользоваться сервисом. | Should |
| US-11 | Пользователь | Как пользователь, я хочу видеть в личном кабинете статистику проверок, найденных угроз, XP и текущий уровень. | Should |
| US-12 | Пользователь | Как пользователь, я хочу получать награду только за новые подтвержденные угрозы, чтобы систему нельзя было накручивать повторной отправкой одной ссылки. | Must |
| US-13 | Пользователь | Как пользователь, я хочу видеть полученные и еще не открытые достижения, чтобы понимать дальнейшие цели. | Could |
| US-14 | Администратор | Как администратор, я хочу видеть найденные пользователями подозрительные ссылки, чтобы подтверждать угрозы и контролировать качество базы. | Should |
| US-15 | Администратор | Как администратор, я хочу управлять базой вредоносных доменов, чтобы добавлять подтвержденные угрозы и удалять ошибочные записи. | Should |

### Приоритеты

- **Must** — обязательная функция для первой версии
- **Should** — важная функция
- **Could** — дополнительная функция
